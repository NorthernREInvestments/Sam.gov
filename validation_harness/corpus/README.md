# Golden solicitation corpus

All cases in this directory are **curated expected truth**.

## Labels

- `source_type`: usually `SYNTHETIC_VALIDATION_FIXTURE`
- Expected values are **human-authored** — never generated by M3

## Validation depth (Phase E / E.1 / F)

| Depth | Meaning |
|-------|---------|
| `execution_path` | Solicitation text → execution requirements → owner gate → operator workflow |
| `broader_pipeline` | Frozen fixture through classification, identity, qty/UOM, supplier, economics, financing, execution, gate, workflow |
| `adversarial_readiness` | False-ready / false-reject probes |
| `positive_ready` | Curated executable deals expected READY=true |
| `reality` | Phase F REALITY_CASE (R_01–R_12) — realistic frozen / edge / real-source |

### Reality class labels (Phase F)

| Label | Meaning |
|-------|---------|
| `REAL_SOURCE_FIXTURE` | Frozen from a real solicitation document in-repo |
| `REALISTIC_FROZEN_FIXTURE` | Realistic structure modeled on real solicitations (not live scrape) |
| `SYNTHETIC_EDGE_CASE` | Intentional trap (e.g. HD UOM) |

Do **not** label synthetic Phase E cases as real.

Compare via: `python -m validation_harness run`

Do not add live government records here without freezing source documents and a human-reviewed `expected` block.
