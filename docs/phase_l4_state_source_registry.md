# Phase L.4 — State Source Registry

Structured coverage for all 50 states (plus BidNet DC network).

Per state tracks:

- primary procurement portal
- platform / adapter family
- public searchability
- auth requirements
- priority tier (1=best public commercial access … 3=gated)

BidNet Direct statewide open-bids listings provide multi-agency commercial density **without** claiming exclusive statewide coverage.

Module: `phase_l.commercial_feed_expansion.state_source_registry()`
Source matrix: `discovery/state_matrix.py` + `discovery/bidnet_network.py`
