# M3 Operator Cheat Sheet

**One page · Open `/ops`**

### MORNING
Open **Today**. Work top **CALL TODAY** first.

### CALL
Phone / RFQ → ask Must Ask → enter price, freight, lead time → notes → **Save Call**.  
If quote promised → set date → lands in **Follow Up**.

### QUOTES
**Quotes** → review new → check landed cost → follow recommendation → Save.

### REGISTER
**Registrations** → HIGH first → walkthrough → **Mark Registered**.

### BID
**Bid Prep** → checklist → **Start Bid Package** (when ready).

### BLOCKED
Read reason. Often “no action inside M3” (e.g. waiting on CAGE). Leave it.

### WATCH
Future / weak evidence. Not a call queue.

### IF STUCK
Use the **one primary button**. Ignore Advanced / phase names. Toggle Training for hints.

### SAVE
Always wait for **Saved · timestamp**. Warn on unsaved leave.
