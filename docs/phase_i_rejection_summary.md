# Phase I — Rejection Summary

## Why deals died (ranked)

| Reason | Role in funnel |
|--------|----------------|
| Not product / vague listing | Dominant Stage A→B reject |
| No recent government price history | Dominant Stage D hold |
| Identity UNKNOWN (FSC--NOUN, no NSN) | Blocks quote even when history strong |
| Ancient-only awards | History WEAK — economics not actionable |
| Repair / overhaul titles | Hard reject (not resale) |
| Vehicle / BOA holder required | Eligibility gate (3 blocked early) |
| New Manufactured Material / OEM path | Deprioritized; often ancient sole-source |
| Service / construction / sources sought | Hard reject |
| Owner cash | None forced; funding unproven for all |
