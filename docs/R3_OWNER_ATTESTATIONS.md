# R3 — Owner Attestations

**Module:** `response_engine.owner_attestations`  
**Object:** `OwnerAttestation`

## Rules

- M3 may prepare the question and proposed answer
- M3 must **not** answer on the owner’s behalf
- Explicit click: Confirm YES / Confirm NO / Need Review
- High-risk reps: no background auto-confirm; no silent library reuse for Section 889
- Versioned audit: who / when / exact question / exact answer / source
- Library (`CompanyAttestationLibrary`) may **suggest** reuse — never auto-submit

## UI copy

Prefer “Need owner confirmation” over clause-number-only jargon. Advanced can show citation.
