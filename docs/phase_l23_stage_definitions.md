# L.23 Stage Definitions

Lifecycle: RAW, FAST_REJECT, ACCESSIBLE_PRODUCT, FAST_RESEARCH_PENDING, FAST_RESEARCH_COMPLETE, DEEP_RESEARCH_PRIORITY, DEEP_RESEARCH_IN_PROGRESS, DEEP_RESEARCH_COMPLETE, READY_TO_CALL, CALLS_IN_PROGRESS, QUOTE_PENDING, QUOTES_RECEIVED, READY_FOR_FINAL_ECONOMICS, READY_TO_BID, SKIP, WATCH, LOW_PRIORITY_RESEARCH, NEEDS_SOURCE_DATA

READY_TO_CALL ≠ READY_TO_BID. Call-ready means worth obtaining real supplier pricing.
