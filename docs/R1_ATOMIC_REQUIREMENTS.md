# R1 — Atomic Requirements

`response_engine.requirements.RequirementCompiler`

## Rule

Material obligations must not remain buried in paragraphs.

## Each requirement carries

- category, mandatory, materiality, timing, curability
- exact provenance (document, page/section/anchor, excerpt, extractor, confidence)
- answer_status / compliance_status
- supersession history (never delete)

## Timing

`PRE_QUESTION_DEADLINE` · `AT_SUBMISSION` · `PRE_AWARD` · `POST_AWARD` · `AT_DELIVERY` · …

## Curability

Defaults conservative. Never “we can probably fix later” without authority.
