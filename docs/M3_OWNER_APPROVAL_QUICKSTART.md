# M3 Owner Approval Quickstart

**Read time: ~5 minutes**

You only handle work the operator cannot finish alone.

## Where to look

1. Open `/ops` → **Home** → **OWNER ACTIONS**
2. Or **Today** → **OWNER ACTIONS**

## Typical owner actions

| Action | What you do |
|--------|-------------|
| Confirm attestation | Answer the exact legal/compliance question shown |
| Sign documents | Sign the listed files (M3 never signs for you) |
| Approve price / package | Review offer, expected profit label (VERIFIED/PROVISIONAL/SCENARIO), warnings |
| Final approval | After clean preflight: **APPROVE FOR SUBMISSION** |
| Verify receipt | If submission is unconfirmed — capture confirmation now |

## Final review screen (concept)

Buyer · Solicitation · Offer · Expected profit · Due · Technical · Compliance · Documents · Warnings

Buttons: **APPROVE FOR SUBMISSION** · **REQUEST CHANGES**

## After approval

Operator follows guided portal/email/physical steps. You still confirm the legally binding final click when required.

## After submission

Confirm receipt (confirmation number / PDF / email). Deal moves to **AWAITING RESULT**.
